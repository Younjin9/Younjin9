### 🤝 Aidea — 위치 기반 AI 숏폼 모임 매칭 플랫폼

> *"내 주변의 즐거움, 숏폼으로 탐색하고 AI로 똑똑하게 연결하세요."*

- **담당:** WebSocket 실시간 채팅 서버 구축, 알림 시스템, 카카오 API 연동
- **기술:** Spring Boot 3.3 · Java 17 · MySQL · Redis · AWS Bedrock · Kakao Maps API · Docker
- **성과:** N+1 쿼리 최적화로 서버 안정성 확보 / 실시간 채팅 메시지 큐 구조 설계
